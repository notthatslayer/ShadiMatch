# ShaadiMatch

A responsive, frontend-only matrimonial website demo built with HTML5, CSS3, and vanilla JavaScript.

## Run it
1. Extract the project folder.
2. Open `index.html` in a modern browser. No build step is needed.
3. For the smoothest local development experience, open the folder in VS Code and use the Live Server extension.

## Included
- Responsive landing page and navigation
- Profile cards with search and religion, education, and location filters
- Grid/list view toggle and profile details modal
- Shortlist and interest actions saved in browser localStorage
- Multi-step registration form with validation
- Demo login and contact forms
- Success story carousel controls
- Dark mode toggle
- About section and developer credit for Tayyaba Shaikh

## Notes
This is a frontend demonstration. It has no backend, real authentication, secure messaging, or database. Registration details, shortlist, interests, and theme preference may be stored in the current browser's localStorage. Do not enter sensitive information. Profile data and success stories are fictional demo content, and photos load from Unsplash over the internet.
